# Transporter profiles in customer quotes

On the mobile **Quote requests** page, **View profile** opens the transporter’s profile within the customer workspace. The **Quotes** tab stays selected. **Back to quotes**, at the top and bottom, returns to the quote requests list. If the customer’s session has ended, that profile link opens customer sign-in.

The summary uses the transporter’s existing profile photo, verification status, visible review ratings, customer-confirmed delivery count and reported years operating. The gallery shows the transport vehicle first when available; **View all** reveals additional uploaded photos. Reviews keep their booking labels and transporter replies. The four most recent customer-confirmed deliveries appear below the reviews.

The mobile layout applies to customers below 1024 px. Desktop, transporter and admin views retain their existing layout and permissions.
